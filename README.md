# FGO IrRemote

**Télécommande infrarouge Android pour la barre de son LG SK5.**
 Application 100 % gratuite, sans publicité, sans abonnement !

**Android infrared remote control for the LG SK5 soundbar.**
 Application 100% free, ad-free, no subscriptions !

---

## 🇫🇷 Français

### Présentation

FGO IrRemote est une application Android gratuite permettant de contrôler une barre de son **LG SK5** depuis un smartphone équipé d'un émetteur infrarouge (IR).

### Fonctionnalités

- Allumer et éteindre la barre de son
- Changer de source audio
- Régler le volume et couper le son
- Contrôler la lecture multimédia (lecture/pause, précédent, suivant)
- Changer les effets sonores
- Détecter la présence d'un émetteur infrarouge sur le téléphone

### Compatibilité

- **Barre de son :** LG SK5
- **Télécommande de référence :** AKB75595416
- **Appareil requis :** smartphone Android équipé d'un émetteur infrarouge

La compatibilité avec d'autres modèles LG n'est pas garantie.

### Téléchargement

La première version publique **v0.9.0** sera prochainement disponible dans la section [Releases](../../releases).

## 🇬🇧 English

### About

FGO IrRemote is a free Android application that lets you control an **LG SK5 soundbar** using a smartphone with a built-in infrared (IR) blaster.

### Features

- Power on/off
- Switch audio inputs
- Adjust volume and mute
- Media playback controls (play/pause, previous, next)
- Change sound effects
- Detect whether the phone has an infrared transmitter

### Compatibility

- **Soundbar:** LG SK5
- **Reference remote:** AKB75595416
- **Required device:** Android smartphone with an IR blaster

Compatibility with other LG models is not guaranteed.

The first public version, **v0.9.0**, will soon be available in [Releases](../../releases).
